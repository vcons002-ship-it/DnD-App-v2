# Cultist Fanatic left casting hand repair

The selected corrected source sheet describes one left hand in four views.
The initial sheet had an inconsistent back view and was rejected before 3D generation.
Both Hunyuan shape and texture generation used the four corrected named inputs.
Source art is 1254 square, cropped views 619 square, final textures 2048 square.

The original hand and detached fingertip were removed. The new wrist was fitted
to the measured cuff, with its root inside the sleeve. The body, weapon and base
coordinates outside the hand cut are preserved, as is the original body texture.
The final GLB has two JPEG95 atlases, 38,584 triangles and 2,709,168 bytes.

Generation, compression, fitting and packaging receipts record hashes and settings.
The scripts retain their original local production paths. Dense and intermediate
GLBs remain in the production folder; only the final runtime model is shipped.
The original runtime GLB is available in Git at commit 793ab87178cea9ec68fadeaf4e6fb0a704de8cdf.
